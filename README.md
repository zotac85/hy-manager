# Hysteria2 Server Manager

Скрипт для установки и управления Hysteria2 на Ubuntu/Debian. Управление через интерактивное меню `hys`.

## 📦 Установка

Одна команда на чистом сервере:

    bash <(curl -fsSL https://raw.githubusercontent.com/zotac85/hy-manager/main/install.sh)

После установки запуск меню:

    hys

## 🖥️ Возможности

### 🚀 Быстрый старт
- **Полный автосетап** — установит Hysteria2, освободит порт 53, получит сертификат Let's Encrypt, создаст конфиг, настроит автопродление, запустит сервис

### 🔧 Hysteria2
- Показ текущей версии
- Установка / запуск / перезапуск / остановка
- Просмотр логов (30 строк)
- **Обновление до последней версии** или выбор конкретной из GitHub
- Проверка наличия новой версии
- Полное удаление

### 🎛️ Панель h-ui
- Установка через systemd (без Docker)
- Управление сервисом
- Просмотр логов
- Удаление

### 🌐 Mimic (UDP → TCP)
Маскировка UDP-трафика под TCP для обхода блокировок провайдера.
- Установка / включение / отключение / удаление
- ⚠️ Требует поддержки на стороне клиента

### 🛡️ Безопасность и сеть
- **UFW**: настройка / удаление / статус
- **Fail2Ban**: настройка / удаление / статус
- **🌐 Оптимизация сети**: BBR + увеличенные буферы UDP/TCP
- **🔎 Проверка сетевых настроек**

### 📜 Сертификаты
- Получение / обновление Let's Encrypt
- Показ отпечатка SHA-256 (для pinSHA256)
- Настройка автопродления через cron
- Удаление Certbot и сертификатов

### ⚙️ Параметры
- **Сменить SNI**
- **Сменить URL маскировки**
- **Сменить пароли** (auth + obfs)
- **Сменить домен** (получает новый сертификат)

### 🔍 Проверки и инфо
- Проверка маскировки
- Показ отпечатка сертификата
- Показ ключа для Happ (подробно)

### 📝 Редактирование
- Ручное редактирование конфига через nano с бэкапом

### 💾 Бэкап и восстановление
- **Бэкап** — сохраняет конфиг, сертификаты, сервис, Let's Encrypt, БД h-ui
- **Восстановление** — распаковка архива на новом сервере

### 🔄 Обновление скрипта
- Скачивание последней версии из GitHub

## 🔑 Ключ для Happ

Внизу главного меню показывается готовый ключ с `pinSHA256`:

    hysteria2://USER:PASS@DOMAIN:53/?sni=dl.google.com&obfs=salamander&obfs-password=XXX&pinSHA256=XXX#Hysteria

Скопируйте и импортируйте в Happ через буфер обмена.

## 🚀 Быстрый старт на чистом сервере

1. Установите скрипт:

       bash <(curl -fsSL https://raw.githubusercontent.com/zotac85/hy-manager/main/install.sh)

2. Запустите меню:

       hys

3. Выберите **1) Полный автосетап**

4. Настройте UFW и Fail2Ban: `hys` → **5) Безопасность и сеть**

5. Включите BBR: **5)** → **7) Оптимизация сети**

6. Скопируйте ключ из меню и вставьте в Happ.

## 📱 Настройка клиента (Happ)

| Параметр | Значение |
|----------|----------|
| Протокол | Hysteria2 |
| Адрес | Ваш домен |
| Порт | 53 (или ваш) |
| Пароль | `Hy2_...` (из конфига) |
| SNI | `dl.google.com` (или ваш) |
| Obfs | `salamander` |
| Obfs-пароль | `Salam_...` (из конфига) |
| pinSHA256 | Отпечаток вашего сертификата |

## 🔄 Переезд на новый сервер

1. На старом сервере: `hys` → **10) 💾 Бэкап**
2. Скачайте `/root/hysteria-backup.tar.gz` на компьютер
3. На новом сервере: установите скрипт одной командой
4. Загрузите бэкап: `scp hysteria-backup.tar.gz root@NEW_IP:/root/`
5. На новом сервере: `hys` → **11) ♻️ Восстановить из бэкапа**

## ⚠️ Важные замечания

- **Порт 53** используется для Hysteria. `systemd-resolved` автоматически отключается при автосетапе
- **UFW может заблокировать SSH**. Скрипт сначала разрешает SSH, потом включает файрвол
- **После смены сертификата** отпечаток `pinSHA256` меняется — обновите ключ в клиенте
- **Mimic** требует поддержки на клиенте — не включайте, если клиент не умеет
- **Brutal CC** (bandwidth в конфиге) — это **целевая** скорость, а не жёсткий лимит. Multi-stream тесты могут её превышать
